ESTUN Studio STEP import runtime
===============================

The ESTUN Studio application and planner are written in C#. An isolated Python
worker calls OpenCascade to parse STEP BRep geometry and produce a neutral JSON
mesh/seam description. The worker does not connect to a network at runtime.

The Windows portable distribution includes the following unmodified packages:

The OpenCascade wheel also bundles unmodified optional native dependencies for
its image/visualization modules: FreeImage, FreeType, OpenEXR/Imath, libjpeg-turbo,
Little CMS, Lerc, XZ/liblzma, libpng, libwebp, OpenJPEG, LibRaw, libtiff, zlib,
zstd, libdeflate, and Microsoft C++ runtime libraries. The complete upstream
package is retained rather than selectively rebuilding its binary dependency
graph. The upstream project/source links and license notices are listed in
cad-licenses/native-dependencies.txt.

SetupCad.ps1 downloads only the pinned official Python archive and the two
PyPI wheels; SHA256 hashes are checked before extraction. To prepare the runtime
from a source checkout, run:

  powershell -NoProfile -ExecutionPolicy Bypass -File tools/SetupCad.ps1

No system Python/pip installation is required. Copy the complete generated
.tools/cad-python folder to Build/CadRuntime when packaging. The setup script
also installs this notice, license copies, and the worker into that folder.
